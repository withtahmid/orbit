Event detail redesign lives in `src/pages/space/events/EventDetailPage.tsx` (layout + big inline `ED_STYLES` `<style>` string), `eventCharts.tsx` (recharts v3 + hand-rolled SVG `RadialBudgetGauge` + `DayOfWeekStrip`), `eventUI.tsx` (`StatTile`, `Money`, `Skeleton`). Uses scoped `.orbit-design` tokens (see [[budgets-ui-conventions]] for measured token contrast). Dark theme only.

**Full-bleed shell:** `.ev-root { margin:-1.5rem -1rem; }` (`-2rem` ≥768px) breaks out of the routed content padding — couples to the parent shell's exact padding; `min-height:100vh` + negative top margin can add a hair of vertical scroll. `.ev-detail-scroll` has NO max-width (side gutters intentionally removed) — everything stretches on ultrawide (6-col stat grid, transactions list, where-grid all span full 1920px+). Consider a centered max-width if ultrawide readability is raised.

**Grid breakpoints (all in ED_STYLES, latest working-tree state):** KPI band is now `.ev-kpis` — `display:grid; grid-template-columns:repeat(auto-fit,minmax(150px,1fr)); gap:16px 24px` with `.ev-kpi--lead{grid-column:1/-1}` (Spent leads its own full-width row, Money size30). NO border/divider rules on `.ev-kpi` anymore → the old stray-vertical-rule-on-wrap bug (721–1250px) is structurally gone. `repeat(2,minmax(0,1fr))`@≤520. budget `minmax(240,320) 1fr` → 1col@≤860. donut-wrap `minmax(0,260px) 1fr` → 1col@≤620 (align-items:start). where-grid `1.4fr 1fr` → 1col@≤720, plus `--single`(1fr) modifier when only locations OR only DOW renders (XOR at EventDetailPage ~L543). donut-legend `auto-fit minmax(220,1fr)` capped max-width 820 (→3 cols) / 560+minmax(200) @≤1100 (→2 cols) / 1 col mobile. Phone overrides @≤640. Reflow clean 1920→320.

**Round-1/2 traps NOW FIXED (verified round 3, feat/enevt/details working tree):** timeline merged into a SINGLE `ComposedChart` (h264, left `cum` axis for area/lines, hidden right `vol` axis domain[0, maxDaily*3.6] so bars fill bottom ~28%) — bar/curve x-alignment resolved. `--fg-4` promoted to `--fg-3` on captions; tooltip count via `.ev-tt-muted`; DOW peak `--fg`/non-peak `--fg-3`. `:focus-visible` rings added (back, tx-chip, search-clear, donut-legend-row). Type chips now `aria-pressed` toggle buttons (correct pattern). Donut legend rows are real `<button>` with `onClick` toggle-pin. `prefers-reduced-motion` guarded in CSS + `usePrefersReducedMotion` hook. Mobile inputs 16px + heights 42/36px. Stat value span truncates.

**Round-3 traps NOW FIXED (verified round 4, feat/enevt/details working tree):** stat grid → `minmax(160,220px)`+`justify-content:start` (sparse rows left-pack as chips). Timeline expense+income `<Bar>`s both `stackId="vol"` (stack into one centered volume bar, no dodge) and declared AFTER `<Area>` BEFORE `<Line>`s (z-order clean). `"No description"` → `--fg-3`. Estimate stat tile now gates `!== null && > 0` (matches BudgetCard, no phantom $0 tile). Donut legend rows `aria-pressed`. Donut legend still 3-col/32px gap (≤1100: 2-col/24px).

**Drillable CategoryDonutChart (eventCharts.tsx ~L358-561, feat/enevt/details):** hand-rolled recharts Pie (NOT the shared components/shared/charts/DrillableDonut.tsx — divergence to confirm). Breadcrumb `.ev-donut-crumbs` flex-wrap + per-crumb max-width:180 ellipsis, current crumb disabled+bold; clean. Legend rows real buttons, aria-pressed + aria-label, focus ring OK, no meaningful fg-4. KNOWN TRAP: `active` state doubles as hover AND pin — clicking a LEAF slice/row on desktop clears the readout (hover pre-sets active, click toggles to null) → feels dead. Fix = separate `hover` vs `pinned` state. Minor: drillable chevron shifts vals/% ~23px vs non-drillable rows (reserve trailing slot); crumb touch targets ~20px on mobile (no @640 override); center `.eyebrow` doesn't truncate (long "· direct" names spill hole). Center %-of-total is correctly relative to current level.

**Also fixed in latest working tree:** shimmer `@keyframes ov-shimmer` (0%→100%: bg-pos 100%→-100%) hoisted GLOBAL into orbit-design.css + `@media(prefers-reduced-motion)` disables `.orbit-design [style*="ov-shimmer"]` — reusable `Skeleton` (eventUI.tsx, inline `animation:ov-shimmer …`) now actually shimmers on this page and the attr-substring selector matches. Hero action buttons: `.orbit-design .ev-hero-actions .od-btn{height:36px}` (40px@≤640) beats `od-btn-sm` 30px on specificity (0,3,0 > 0,2,0) — covers Edit/Delete AND labeled EventStatusButton. `.ev-budget-card{align-items:stretch}` + gauge centered by `.ev-budget-body`(align/justify center, flex:1) → Budget header left-aligns like sibling sections. Skeleton heights 210/300/280 (reduced CLS). Timeline `volMax=maxDaily*3.6` now scales off the STACKED sum (maxD tracks expense+income), so stacked-bar height stays ~28%.

**Remaining (minor/accepted):**
- KPI band is now auto-fit fill (no left-pack whitespace). Possible cosmetic: when non-lead metric count mod columns == 1, the last row shows a single left-aligned orphan cell with empty space to its right (inherent to auto-fit grids). Not a regression; acceptable.
- Stacked daily bar both-expense-AND-income day: both segments carry `radius=[2,2,0,0]` → tiny rounded-corner seam between them; income daily bar unlabeled (legend "Income" names the cumulative LINE). Low pri (income on events is rare).
- Sub-44px touch targets persist (accepted/minor): tx-chip 36px, back ~30px, search-clear 28px, donut-legend-row ~32px mobile.
- Remaining `--fg-4` is all decorative icons + the search `::placeholder` — no meaningful body text left in fg-4.
